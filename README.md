# rails-intro

Ruby on Rails の学習用プロジェクトです。

| 項目 | バージョン |
|------|-----------|
| Ruby | 3.4.10 |
| Rails | 8.1.3 |
| DB | MySQL 8.0 |

## 最短手順

1. リポジトリを開き、コマンドパレットから **「Dev Containers: Reopen in Container」** を実行する
2. コンテナ内のターミナルで開発サーバーを起動する

```bash
bin/dev
```

3. ブラウザで [http://localhost:3000](http://localhost:3000) を開く

詳細なセットアップ手順は [docs/setup.md](docs/setup.md) を参照してください。
